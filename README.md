# Euro Visa Guide

I'm planning to build a visa application tracker for the countries in Europe, since we have a lot of students who are on an F1 visa in the United States and go on multiple trips for the GIPs and recreational trips within the European countries. Can I have a working app wherein I can select a country and get the visa guidelines for that particular country?
